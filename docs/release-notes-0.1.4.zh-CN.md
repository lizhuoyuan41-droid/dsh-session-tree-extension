# DSH Session Tree 0.1.4 更新说明

本次更新集中修复分叉分支栏的显示与动画问题，并调整完成提醒的位置。

## 分叉分支栏

- 分叉分支栏默认折叠；宿主启动或页面重载后不会自动展开。
- 折叠再展开工作区时，保留各分支栏原本的开合状态。
- 只有归档分叉的分支栏仍挂在对应父会话行下；栏头按“活动分叉 / 归档筛选”组合显示，不再出现 `x0`。
- 长分支栏收起时按内容高度调整时长（约 200–600 ms），并临时关闭侧栏滚动锚定，避免下方会话被“钉住”或动画失效。

## 工作区展开动画

- 工作区展开时，新增的会话行在自己的最终位置淡入，不再从整个工作区上方滑入。
- 下方已有会话行从点击前的可见位置移动到新的布局；隐藏行不参与起点计算。

## 完成提醒

- 分叉会话完成后，绿点显示在分叉会话行的前端。
- 分叉分支栏折叠时，绿点仍显示在分支栏末尾（标题与数量之后），折叠、展开都可见。
- 父会话行不再显示插件添加的绿点。
- 嵌套分叉折叠时，已完成后代的提醒汇总显示在父分叉行前端；打开分叉后提醒由宿主状态清除。

## 其他

- 新建分叉的输入框保持空白，不再回填上一次提问。
- 分支栏使用页面进程级开合状态；宿主重启后恢复默认折叠。

功能构建通过 226 项测试、宿主/客户端类型检查、构建与四包 `--pack` 校验。更新后请刷新页面；desktop 需完整退出应用后重新打开，以加载新客户端。

本版本提供四个 npm 格式安装包，版本统一为 0.1.4。源码标签与 npm 注册表发布是独立步骤；在注册表发布前，请勿假定插件市场已经提供 0.1.4。离线安装需同时提供四包，不能只复制 carrier 包而依赖注册表下载其余三个包。

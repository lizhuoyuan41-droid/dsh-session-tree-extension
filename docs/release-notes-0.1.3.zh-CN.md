# DSH Session Tree 0.1.3 更新说明

本次更新主要改进分支聚焦和聊天中的分叉操作，让分支的查看与继续编辑更一致。

## 分支聚焦更准确

“聚焦此分支”按钮移到带有“分叉”或“克隆”徽标的分支首行。点击后，只查看该分支及其嵌套分叉，主线后续和其他分支不再混入；没有下级分叉的叶子分支也可聚焦。

共享分叉锚点不再显示聚焦按钮。点击“全部”、× 或按 Esc，仍可恢复完整视图。

## 聊天分支按钮接入会话树

聊天末尾的“在新对话中分支”按钮现在复用会话树分叉流程：创建子会话、登记父子关系，并将该轮提示词填入新会话输入框，方便编辑后继续。按钮名称保持原样，草稿不会自动发送。

## 操作更稳妥

- 兼容旧会话缓存，按实际点击的会话和轮次定位分叉节点。
- 防止同一源会话的重复点击同时创建多个分叉。
- 分叉失败时显示原因；正常用户输入不再因特殊文字前缀被误当成系统注入。
- 保留原生权限与不可用按钮状态。

## 使用说明

会话树目前仍仅支持从最新用户轮次分叉，本次未开放任意历史轮次分叉。点击不符合条件的历史轮次会显示提示。

功能构建已通过 214 项测试、类型检查和构建，并完成真实按钮分叉验证：提示词正确填入、父子关系正确，源会话日志未被改写。更新后请刷新页面或退出重开 desktop，以加载新客户端。

本版本提供四个 npm 格式安装包，包版本统一为 0.1.3。源码标签与 npm 注册表发布是独立步骤；在注册表发布前，请勿假定插件市场已经提供 0.1.3。离线安装需同时提供四包，不能只复制 carrier 包而依赖注册表下载其余三个包。
